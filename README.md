## How to run it

The easiest way to try the tool is to download the Python file from this repository. You'll then be able to run it straight from your computer's Terminal (or Command Prompt, if you're a Windows guy).

1. Click `head_geek.py` above.
2. Click the **Download raw file** button (or the download icon).
3. Save the file somewhere easy to find.
4. Make sure **Python 3** is installed on your computer. (If not, you can grab it from [Python.org](https://www.python.org/).)
5. Open Terminal (Mac) or Command Prompt (Windows).

### If you're a Mac guy 🍎

First, navigate to the folder where you saved the file.

Type:

cd

Leave a space after cd, then drag the folder containing head_geek.py into Terminal.

Press Enter.

Check the file is there by running:

ls

You should see:

head_geek.py

Then, to ACTUALLY start the tool, run:

python3 head_geek.py



### If you're a Windows guy 🪟

Open Command Prompt and navigate to the folder where you saved the file.

Type:

cd

Leave a space after cd, then drag the folder containing head_geek.py into Command Prompt.

Press Enter.

Check the file is there by running:

dir

You should see:

head_geek.py

Then, to ACTUALLY start the tool, run:

python head_geek.py
